Ce qui doit sortir sans réfléchir

Lire un intervalle et dire si une borne est dedans. En écrire un à partir d’une phrase. Faire une intersection et une réunion. Distinguer « et » de « ou ».

Les quatre intervalles

[3 ; 7] — les deux bornes sont dedans

]3 ; 7[ — les deux bornes sont dehors

[3 ; 7[ — 3 dedans, 7 dehors

]3 ; 7] — 3 dehors, 7 dedans

Le crochet tourné vers l’intérieur prend la borne. Tourné vers l’extérieur, il la laisse dehors. Il n’y a rien d’autre à retenir, et cela suffit pour les quatre cas.

Appartenir, être inclus

Le symbole Se lit S’emploie pour
∈ appartient à un élément dans un ensemble
⊂ est inclus dans un ensemble dans un autre
∩ inter ce qui est dans les deux
∪ union ce qui est dans l’un ou l’autre

∈ et ⊂ ne se remplacent pas. Un nombre appartient à un ensemble ; un ensemble est inclus dans un autre. 5 ∈ [0 ; 10] est correct, 5 ⊂ [0 ; 10] ne veut rien dire.

Et, ou, contre-exemple

« et » : les deux conditions à la fois → c’est une intersection

« ou » : au moins une des deux → c’est une réunion

Un seul contre-exemple suffit à démolir une phrase en « tous les… ». Pour réfuter « tout nombre entier est positif », il suffit d’écrire − 3. On n’a rien à démontrer de plus.

Pour aller plus loin

Les trois emplois du signe =Pour aller plus loin›

Le même symbole sert à trois choses, et les élèves n’en voient qu’une.

Une égalité : 3 + 4 = 7. Un constat, vrai une fois pour toutes.

Une identité : 3x + 5x = 8x. Vrai pour toutes les valeurs de x. Il n’y a rien à chercher.

Une équation : 3x = 12. Vrai pour certaines valeurs seulement — ici, une seule. Là, il y a quelque chose à chercher.

La question « qu’est-ce que ce signe = me demande de faire ? » évite de résoudre une identité, et de rester bloqué devant une égalité qui n’attendait rien.

On remplit chaque case, puis on vérifie la série entière d’un coup.

Série 3 — intersection et réunion

  1. A = [0 ; 10] et B = [5 ; 20], A inter B
  2. A et B, A union B
  3. B = [5 ; 20] et C = [12 ; 30], B inter C
  4. B et C, B union C
  5. A = [0 ; 10] et C = [12 ; 30], A inter C

L’intersection garde ce qui est dans les deux, la réunion garde tout. Dessinez les deux segments l’un sous l’autre.

Série 5 — vrai ou faux

  1. 6 est pair et multiple de 3
  2. 7 est pair ou premier
  3. 9 est premier ou multiple de 4
  4. 10 est pair et premier
  5. tout nombre entier est positif
  6. il existe un entier négatif
Avec « et », les deux doivent tenir. Avec « ou », une seule suffit. Pour « tous les », un contre-exemple suffit à dire faux.

Le quiz

  • Dans [3 ; 7[, le nombre 7 est : inclus | égal à 3 | exclu
  • « x ∈ [0 ; 5] » veut dire : x vaut 0 ou 5 | x dépasse 5 | x est entre 0 et 5, bornes comprises
  • Pour montrer qu’une phrase en « tous les… » est fausse, il suffit : d’un long calcul | de la réécrire | d’un seul contre-exemple
  • Dans « 3x = 12 », le signe = introduit : une identité | une définition | une équation
  • Le symbole ∩ garde ce qui est : dans l’un ou l’autre | dans aucun | dans les deux
