Ce qui doit sortir sans réfléchir

Lire les coordonnées d’un point. Placer un point à partir de ses coordonnées. Nommer les deux axes et l’origine.

Le vocabulaire, en quatre mots

Un point se note ( x ; y ).

  • xest l’abscisse : on la lit sur l’axe horizontal
  • yest l’ordonnée : on la lit sur l’axe vertical
  • le point ( 0 ; 0 ) est l’origine

L’abscisse d’abord, l’ordonnée ensuite. Le moyen de ne plus se tromper : dans l’alphabet, a vient avant o — abscisse avant ordonnée. Et sur la feuille, on avance avant de monter.

Lire, puis placer

  1. Pour lire : je descends du point jusqu’à l’axe horizontal, j’y lis l’abscisse ; puis je vais du point vers l’axe vertical, j’y lis l’ordonnée.
  2. Pour placer : j’avance sur l’axe horizontal jusqu’à l’abscisse, puis je monte — ou je descends — de l’ordonnée.

Un point sur un axe a une coordonnée nulle. Le point ( 5 ; 0 ) est sur l’axe horizontal, et ( 0 ; −2 ) est sur l’axe vertical. Le zéro n’est pas une absence : c’est une information.

Pour aller plus loin

Les nombres négatifs, et les quatre quartiersPour aller plus loin›

Les deux axes découpent la feuille en quatre zones. À droite de l’axe vertical, l’abscisse est positive ; à gauche, elle est négative. Au-dessus de l’axe horizontal, l’ordonnée est positive ; en dessous, négative.

Le point ( −2 ; 1 ) est donc en haut à gauche, et ( 3 ; −4 ) en bas à droite.

On peut retrouver la zone avant de placer le point, rien qu’aux deux signes. C’est un contrôle gratuit : si le point tombe ailleurs, on s’est trompé de sens.

Je m’entraîne

On remplit chaque case, puis on vérifie la série entière d’un coup. Les quatre points sont ceux du schéma ci-dessus.

Le quiz

  • Dans ( 3 ; 2 ), le 3 est : l’ordonnée | l’origine | l’abscisse
  • ( 2 ; 3 ) et ( 3 ; 2 ) sont : le même point | symétriques | deux points différents
  • Le point ( 5 ; 0 ) est : à l’origine | hors du repère | sur l’axe horizontal
  • Un point d’abscisse négative est : en haut | en bas | à gauche
  • L’origine se note : ( 1 ; 1 ) | ( 0 ; 1 ) | ( 0 ; 0 )
